
# Lung Cancer Detection Using CNN

## Project Description
This project uses a Convolutional Neural Network (CNN)
to classify lung CT scan images into three categories:
- Normal
- Benign
- Malignant

This project is developed for educational purposes and
is not intended for medical diagnosis.

## Dataset
IQ-OTH/NCCD Lung Cancer Dataset.

The dataset contains CT scan images from three classes.
Images are resized to 224 x 224 pixels and normalized
before being used by the model.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Pillow (PIL)
- Scikit-learn
- Matplotlib
- Google Colab

OpenCV and Streamlit may be used in the application
as the project develops.

## Model
A baseline Convolutional Neural Network (CNN) is trained
to classify the three image categories.



## . Preliminary Results
- Test accuracy: 98.18%
- Test images: 165
- Correct predictions: 162
- Incorrect predictions: 3
